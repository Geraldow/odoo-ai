# Migration Guide: Odoo 16 → 17

## CRITICAL: attrs Attribute Removal
The `attrs` attribute has been completely removed in Odoo 17. All visibility, readonly, and required conditions must be migrated to inline expressions.

### Migration Example
```xml
<!-- Before (v16) -->
<field name="partner_id"
       attrs="{'invisible': [('state', '=', 'draft')],
               'readonly': [('state', '!=', 'draft')]}"/>

<!-- After (v17) -->
<field name="partner_id"
       invisible="state == 'draft'"
       readonly="state != 'draft'"/>
```

### Expression Syntax Reference
| attrs Domain | v17 Expression |
|--------------|----------------|
| `[('field', '=', value)]` | `field == value` |
| `[('field', 'in', [a,b])]` | `field in [a, b]` |
| `['&', A, B]` | `A and B` |
| `['|', A, B]` | `A or B` |
| `['!', A]` | `not A` |

## Mandatory: Create Method Migration
The `@api.model_create_multi` decorator is now required for all `create` methods.

```python
# REQUIRED in v17
@api.model_create_multi
def create(self, vals_list):
    for vals in vals_list:
        # process vals
        pass
    return super().create(vals_list)
```

## New View Features

### column_invisible
Tree views now use `column_invisible` to hide columns based on conditions or context.

```xml
<tree>
    <field name="name"/>
    <field name="cost" column_invisible="not context.get('show_cost')"/>
</tree>
```

### Parent Field Access
Domain expressions in embedded views can now access the parent record.

```xml
<field name="line_ids">
    <tree editable="bottom">
        <field name="product_id" invisible="parent.state == 'done'"/>
    </tree>
</field>
```

## JavaScript Updates
ES6 modules are now strictly enforced. All imports must use the standard ES6 syntax.

```javascript
/** @odoo-module **/
import { Component, useState } from "@odoo/owl";
import { registry } from "@web/core/registry";
import { useService } from "@web/core/utils/hooks";
```
