# Migration Guide: Odoo 14 → 15

## Breaking Changes from v14

### @api.multi REMOVED
The `@api.multi` decorator has been completely removed in Odoo 15. Methods now iterate by default.

```python
# BREAKS IN v15
@api.multi
def action_confirm(self):
    pass

# v15 REQUIRED
def action_confirm(self):
    for record in self:
        # process record
        pass
```

### track_visibility Deprecated
The `track_visibility` parameter in fields is deprecated in favor of `tracking`.

```python
# DEPRECATED (still works but warns)
state = fields.Selection(..., track_visibility='onchange')

# v15 CORRECT
state = fields.Selection(..., tracking=True)
```

## Migration Steps

1. **Remove @api.multi**: Search for and remove all `@api.multi` decorators in your codebase.
2. **Update Tracking**: Replace `track_visibility='onchange'` or `track_visibility='always'` with `tracking=True`.
3. **Python Version**: Ensure you are using Python 3.7 or higher (3.9 is recommended).
4. **Asset Management**: Odoo 15 introduced a new asset bundle system in the manifest.

```python
'assets': {
    'web.assets_backend': [
        'my_module/static/src/js/my_component.js',
        'my_module/static/src/xml/my_component.xml',
        'my_module/static/src/scss/my_component.scss',
    ],
}
```

## New Patterns in Odoo 15

### OWL 1.x Introduction
Odoo 15 is the first version to heavily use the OWL (Odoo Web Library) framework.

```javascript
/** @odoo-module **/

const { Component, useState, onMounted } = owl;
const { useService } = require('@web/core/utils/hooks');

class MyComponent extends Component {
    setup() {
        this.state = useState({ data: [], loading: true });
        this.orm = useService('orm');

        onMounted(() => {
            this.loadData();
        });
    }

    async loadData() {
        this.state.data = await this.orm.searchRead('my.model', [], ['name']);
        this.state.loading = false;
    }
}
MyComponent.template = 'my_module.MyComponent';
```

### Batch Create
Using `@api.model_create_multi` is recommended for performance.

```python
@api.model_create_multi
def create(self, vals_list):
    for vals in vals_list:
        if not vals.get('code'):
            vals['code'] = self.env['ir.sequence'].next_by_code('my.model')
    return super().create(vals_list)
```
